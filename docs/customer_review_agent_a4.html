검증된 SQL과 Aspect 기반
고객 리뷰 분석 Agent

LLM은 질문을 해석하고, 검증된 코드가 조회·검증·집계를 수행합니다.

1

LLM의 SQL 생성 위험을 제거했다

Agent는 SQL을 직접 작성하지 않고 사전에 구현·검증된 Tool만 선택합니다.

사용자 질문자연어 분석 요청
→
Agent Tool 선택의도·조건 해석
→
검증된 SQL Tool고정 Query·입력 검증
→
PostgreSQL리뷰 표본·정량 통계
LLM 직접 SQL 생성 없음
2

리뷰를 Aspect 단위로 구조화했다

선별 리뷰에서 불만 유형과 판단 근거를 리뷰별 JSON으로 추출합니다.

선별 리뷰저평점·고공감 표본
→
Aspect Extractor LLM불만·감성·직접 경험 분석
→
Aspect JSONTopic·Sentiment·Evidence
3

원문 검증 후 반복 불만을 정량화했다

LLM 결과를 그대로 사용하지 않고 Python 코드로 검증하고 집계합니다.

Aspect JSON리뷰별 추출 결과
→
원문 근거 검증없는 Evidence 제거
→
Python 집계중복 제거·빈도 계산
→
구조화 결과Aspect·빈도·비율·근거
원문에 존재하는 근거만 유지
4

구조화 결과를 Agent 판단 근거로 활용했다

정량 통계와 검증된 Evidence를 최종 LLM 입력으로 제공합니다.

Grounded ContextSQL 통계 + Aspect Pattern
→
Final Agent LLM검증 결과 기반 해석
→
업무 활용 답변반복 불만·영향·개선 우선순위

구현 방식

01

Agent가 질문을 해석해 검증된 SQL Tool을 선택하고, PostgreSQL에서 리뷰 표본과 통계를 조회합니다.

02

Aspect Extractor가 리뷰별 불만 유형·감성·직접 경험 여부와 근거 문장을 구조화합니다.

03

Python에서 Evidence의 원문 존재 여부를 검증하고 Aspect별 빈도·비율과 대표 근거를 집계합니다.

04

최종 Agent는 구조화된 Tool 결과를 입력받아 반복 불만과 제품 개선 우선순위를 제시합니다.

핵심 설계: LLM에는 질문 해석과 의미 분류를 맡기고, 수치 조회·근거 검증·집계는 테스트 가능한 코드로 통제했습니다.
