# Customer Intelligence Agent

고객 리뷰와 상품 데이터를 분석하여 반복 불만, 제품 강·약점, 개선 우선순위를 근거와 함께 제공하는 고객 인텔리전스 에이전트입니다.

## 프로젝트 목표

마케팅·상품기획·VOC 담당자가 많은 리뷰를 직접 읽고 정리하는 과정을 줄이고, 자연어 질문만으로 다음과 같은 분석 결과를 얻도록 설계했습니다.

- 상품 기본 정보와 리뷰 현황 조회
- 평점 분포 및 부정 리뷰 비율 분석
- 반복 불만과 고객 요구사항 도출
- 실제 리뷰에 근거한 제품 강·약점 분석
- 상품·상세페이지·운영 개선안 제안
- 존재하지 않는 상품에 대한 안전한 예외 처리

## 데이터

- Amazon Reviews 2023
- 카테고리: Beauty and Personal Care
- 상품: 555개
- 리뷰: 203,648건
- 부정·중립 리뷰(평점 3점 이하): 50,187건

`rating_number`는 Amazon 상품 메타데이터에 표시된 전체 평점 수이며, `review_count`는 현재 분석 데이터베이스에 저장된 리뷰 원문 수입니다.

## 동작 방식

1. 사용자가 상품 또는 고객 반응에 관한 질문을 입력합니다.
2. 에이전트가 질문에 필요한 조회 도구를 선택합니다.
3. 도구가 PostgreSQL에서 상품 정보와 리뷰 데이터를 조회합니다.
4. 에이전트가 정량 통계와 실제 리뷰 근거를 종합합니다.
5. 주요 발견과 실행 가능한 개선안을 답변으로 제공합니다.

## 기술 스택

- Python
- LangChain Agent
- OpenAI API
- PostgreSQL / pgvector
- Docker Compose
- pandas / Parquet

## Agent Evaluation

실제 PostgreSQL 데이터베이스와 OpenAI API를 사용하여 15개의 고객·상품 분석 시나리오를 평가했습니다. 도구 선택은 규칙 기반으로 자동 평가하고, 답변 품질은 정확성·근거성, 분석 구체성, 업무 활용성을 기준으로 수동 검토했습니다.

### 평가 기준

- 도구 선택 및 인자 적절성: 3점
- 답변 정확성 및 데이터 근거성: 3점
- 분석의 구체성: 2점
- 업무 활용 가능성: 2점

## 대표 평가 사례

| 사례 | 검증 역량 | 결과 |
